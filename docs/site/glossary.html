术语表

共 25 个核心术语。键入关键词可过滤。

FOC
Field Oriented Control，磁场定向控制，把电流分解为励磁 Id 和转矩 Iq。
SVPWM
Space Vector PWM，用空间电压矢量合成三相逆变器占空比。
电角度
电磁场周期对应的角度，等于机械角度乘以极对数。
Id
d 轴电流，通常对应磁链方向；弱磁时常为负。
Iq
q 轴电流，主要产生电磁转矩。
PLL
锁相环，用相位误差估算并平滑角度/速度。
JSQR
STM32 ADC 注入通道序列寄存器；JEXTSEL 选 TIM1 TRGO/CC4 作为触发源，让 ADC 在 PWM 中点自动采样。
BDTR
STM32 高级定时器（TIM1/TIM8）的死区与刹车寄存器；DTG 字段编码死区时间，MOE 是主输出使能。
OCP
Over-Current Protection 过流保护；硬件比较器 (COMP+TIM1 BKIN) 触发为快速 OCP，软件累积 I²t 触发为慢速 OCP。
I²t
电流平方对时间积分，用来等价模拟绕组温升；超过预设阈值即报"长时过流"，区别于瞬时过流。
Z 信号
增量编码器每圈一次的索引脉冲，用来周期性复位累计计数器漂移；接 TIM 输入捕获中断。
CCR
Capture / Compare Register；写入 TIMx->CCR1/2/3 决定三相 PWM 占空比，预装载使能后下一周期生效。
反液击
压缩机启动时限制加速斜坡（典型 300~800 rpm/s），让液态制冷剂有时间气化避免阀片碎裂。
APF
Annual Performance Factor 全年能效比，按 GB 21455 加权多工况点；变频机靠部分负荷高 COP 拉高 APF。
V/f
电压频率比开环拖动；启动初段 BEMF 太小观测不到时使用，按 V_min + k·f 给定电压矢量"硬拖"转子。
抗积分饱和
Anti-Windup；PI 输出撞限时停止 / 反算 (Back-Calc) 积分累加，避免 windup 大超调。
MTPA
Maximum Torque Per Ampere，同电流幅值下最大转矩的工作点轨迹；IPM 上 MTPA 天然带负 Id。
MTPV
Maximum Torque Per Voltage，同电压下最大转矩的工作点；深度弱磁的边界，越过则功率反而下降。
电压椭圆
Id-Iq 平面上 √(Vd²+Vq²)≤V_max 的几何边界；中心 (−ψf/Ld, 0)，半径 ∝ 1/ωe，转速越高椭圆越小。
退磁阈值
永磁体反向磁场 H_d 越过 BH 曲线"膝点"后发生不可逆退磁；高温下阈值降低 (NdFeB ≈ 0.6%/℃)。
EEV
Electronic Expansion Valve 电子膨胀阀；步进电机驱动的针阀，按 SH 闭环 PI 控制冷媒流量。
SH
吸气过热度 = T_suct − T_sat(P_s)；EEV PI 的反馈量。SH<3K 液击预警，>15K 缺氟预警。
SC
冷凝过冷度 = T_sat(P_d) − T_liquid；保证节流前 100% 液态，<2K 时 EEV 流量会被闪发气泡扰乱。
P-h 图
焓压图；蒸气压缩循环 4 状态点 (吸气/排气/过冷液/两相) 在图上构成的多边形是制冷工艺路线图。
压缩机包线
(rpm, 压比) 或 (T_e, T_c) 平面上的机械寿命安全运行区；超出 → 排气温度/油循环/阀片寿命任何一项报废。
