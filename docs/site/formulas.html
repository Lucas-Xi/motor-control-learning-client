坐标变换 / 调制

Clarke 变换
Iα = Ia, Iβ = (Ia + 2Ib) / √3
Park 变换
Id = Iα cosθ + Iβ sinθ, Iq = -Iα sinθ + Iβ cosθ
SVPWM 调制比
m = √3 |Uref| / Udc
Clarke q15 整数实现
Iβ = (Ia + 2·Ib) × 18919 >> 15 (18919 ≈ 32768/√3)
SVPWM min-max 零序注入
voff = −(vmax + vmin)/2; duty = 0.5 + (v + voff)/Udc

FOC 时序与转矩

PMSM 转矩
Te = 1.5 p [ψf Iq + (Ld - Lq) Id Iq]
电频率
fe = (rpm / 60) × polePairs
反电动势
BEMF = Ke × ω_e × polePairs = ψf × ω_e
FOC 总采样-生效延迟
t_delay ≈ 1.5·Ts (ADC 中点 + CCR 预装载); 电流环带宽上限 ≈ 1/(2π·1.5·Ts)
压缩机负载转矩
τ_load = W_comp / ω_m = (m_dot·w) / (2π·rpm/60)

弱磁 / 无感 / 高级

电压极限
√(Vd² + Vq²) ≤ Udc / √3
HFI 凸极信号增益
gain = (r − 1)/(r + 1), r = Lq/Ld; r=1.5 → 0.20, r=2.5 → 0.43
HFI 解调误差
i_response × cos(ωh·t) → LPF → ≈ 0.5·sin(2·Δθ)
弱磁基速
ω_base = V_max / ψf; V_max = Udc/√3 (SVPWM 线性区)
弱磁 Id 前馈解析
Id* = √(V_max² − (ωe·Lq·Iq)²) / (ωe·Ld) − ψf/Ld
IPM MTPA 解析解
Id* = (ψf − √(ψf² + 8(Ld−Lq)²·Iq²)) / (4(Ld−Lq))
电压椭圆
(ψf + Ld·Id)² + (Lq·Iq)² ≤ (V_max/ωe)²; 中心 (−ψf/Ld, 0)

控制器与逆变器

电流环带宽整定
Kp = ω_bw × L, Ki = ω_bw × R (零极点对消)
抗积分饱和 (Back-Calc)
I_term += Kt × (u_sat - u_unsat) × Ts, Kt ≈ Ki / Kp
死区电压损失
ΔV_dt = (t_dead / Ts) × Udc × sign(I_phase)

前级 / 保护 / 启动

I²t 过流积分
I²t = ∫ I² dt (累积到阈值即报 FAULT_OC_I2T)
V/f 启动比例
V_cmd = V_min + (V_rated - V_min) × (fe / fe_rated)
反液击斜坡
dω/dt ≤ rampRpmS; 压缩机典型 300~800 rpm/s
Boost PFC 升压关系
Udc = Vrect / (1 − D); D=0.4 + 220V AC → Udc ≈ 520V (工程限 D≤0.5)
PFC 母线电容纹波
ΔUdc ≈ I_load / (2·ω_line·C); 按目标纹波 % 反推 C
